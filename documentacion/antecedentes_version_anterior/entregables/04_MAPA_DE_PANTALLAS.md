# REPI — Mapa completo de las 97 entradas de pantalla

Este mapa conserva nombres, rutas propuestas y asignaciones del handoff original. No certifica97rutas operativas ni97flujos integrados. Incluye páginas, pestañas, modales, overlays y agrupaciones. Los defectos de ejecución y límites se documentan por separado. Para un handoff nuevo, ampliar este mapa; no usarlo como techo.

Los archivos de prototipo contienen navegación por estado, no el router propuesto. El escritorio legacy está incompleto; las alternativas de intro 1b/1c tienen código pero no son la intro seleccionada. Faltan entradas propias para algunas brechas como reseña del socio y selector dual.
