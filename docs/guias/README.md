# REPI — Guías para la puesta en marcha

Estas guías explican los menús implementados al 27/10/2026 y el trabajo de cada persona. Completan la [carpeta comercial](../comercial/README.md). Revisar el [estado y límites](../comercial/ESTADO_Y_LIMITES.md) antes de incorporar clientes reales.

| Manuel / operación de REPI | [REPI Admin: acuerdo, precio y habilitación](REPI_ADMIN.md) |
| Dueño, gerente, piso o recepción | [Gimnasio y equipo](GYM_EQUIPO.md) |

La navegación depende de los permisos. Si falta una opción, comprobar organización, sede y rol con el responsable. No compartir cuentas, contraseñas, códigos de recuperación ni enlaces de invitación en grupos públicos.

Las guías no fijan un precio, una promesa de soporte o una política jurídica. Esos datos se completan en el acuerdo real. Tampoco certifican pruebas físicas del teléfono ni el estado del sitio en el momento de lectura.
